# Raquete-para-todos

Demonstração do Projeto Raquete para Todos, transferida para este repositório com autorização do senhor Thaynan. O conteúdo em português, as legendas, os textos alternativos e as fotos públicas do export foram preservados. Isto não é o aceite institucional final: os direitos de imagem para o lançamento continuam pendentes.

O site de demonstração fica em `static/` e é o que o GitHub Pages deve publicar. O tema WordPress fica em `theme/raquete-child/`. A documentação está em `docs/` (não faz parte do site). O endereço previsto, depois do merge em `main` e da permissão de Pages, é `https://sfmartinst-debug.github.io/Raquete-para-todos/`. Enquanto o Pages não estiver confirmado, esse endereço não deve ser tratado como no ar.

A home continua com o H1 `Projeto Raquete para Todos`, `noindex, nofollow` e `robots.txt` com `Disallow: /`. Os controles do hero seguem IRIS-05h (setas SVG sobre a foto, pausa compacta, foco amarelo, pontos passivos). A correção IRIS-05g de foto ativa / quadro em branco foi mantida. Detalhes em `docs/distribuicao-github-pages.md` e `specs/IRIS-05h-controles.md`. O inventário de origem está em `docs/HANDOFF.txt`.
