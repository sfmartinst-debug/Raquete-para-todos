# Projeto Raquete para Todos — site de apresentação (v1) — RASCUNHO

Repositório **privado** de trabalho do ANVIL (equipe VANGUARD, IRIS, ECHO, ANVIL, BASTION). Nada aqui está aprovado para publicação.

- `raquete-child/` — tema filho de Twenty Twenty-Five (theme.json com o sistema visual IRIS-01, fontes OFL auto-hospedadas, sem chamadas externas).
- `conteudo/` — export WXR das 7 páginas (textos da ECHO v1, só com blocos confirmados).
- `docs/` — especificação técnica (hipótese), inventário técnico, plano de publicação/reversão (modelo), pendências por agente.
- `scripts/` — scripts do ambiente local (php -S em 127.0.0.1) e de captura de tela.
- `evidencias/` — capturas 1366 / 768 / 390 px.

Sem credenciais, sem banco de dados, sem wp-config.
